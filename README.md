# Telegram Bot Service Intake

Модульная архитектура Telegram-бота для приёма сервисов с полной поддержкой Telegram Premium эмодзи.

## Структура проекта:
- `config.py` — основные настройки, токены, ID администраторов, каналы и рабочие часы
- `emojis.py` — словарь премиум-эмодзи операторов и кнопок (`custom_emoji_id`), теги форматирования текста
- `texts.py` — все пользовательские и административные шаблоны сообщений
- `keyboards.py` — клавиатуры меню, профиля, очередей и админ-панели с кастомными эмодзи
- `database.py` — работа с SQLite (пользователи, операторы, заявки, выводы, настройки, автомиграции)
- `states.py` — FSM-состояния пользователей и администраторов
- `helpers.py` — вспомогательные функции проверки подписки, безопасного редактирования сообщений
- `handlers/` — роутеры обработчиков:
  - `user.py` — команды и сценарии пользователя (/start, сдача сервиса, профиль, вывод, ввод кода)
  - `admin.py` — админ-панель (/admin, /msg, /emoji, управление заявками, операторами, балансом, рассылками)
- `main.py` — точка входа и запуск диспетчера
- `bot.py` — ярлык для запуска (`python bot.py`)

## Запуск:
```bash
pip install -r requirements.txt
python main.py
```
